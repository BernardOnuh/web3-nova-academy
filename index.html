Authentication

Single login endpoint for all roles. Returns a JWT to use in the sidebar.

Tip: After a successful login, copy the token from the response and paste it into the Bearer Token field in the sidebar. All subsequent requests will use it automatically.
POST /auth/login Login — all roles ▶
Cohorts

Super admin only. Create and list cohorts.

POST /admin/cohorts Create cohort ▶
GET /admin/cohorts List all cohorts ▶
Courses

Super admin only for create/delete. Tutors can list their own course.

POST /admin/courses Create course ▶
GET /admin/courses List courses ▶

DELETE /admin/courses/:id Delete course ▶

Admins / Tutors

Super admin only. Assign tutors to courses.

POST /admin/admins Create tutor ▶
DELETE /admin/admins/:id Delete tutor ▶

Students

Create, bulk-create, list, and delete students.

POST /admin/students Create student ▶
POST /admin/students/bulk Bulk create students ▶
GET /admin/students List students ▶

DELETE /admin/students/:id Delete student ▶

Curriculum (Admin)

Seed and manage 12 curriculum weeks per course.

POST /admin/curriculum/seed/:cohortId/:courseId Seed 12 weeks ▶

GET /admin/curriculum Get all weeks ▶

PATCH /admin/curriculum/:id Update week title/description ▶
Assignments (Admin)

One assignment per curriculum week. Auto-calculated open/close window: Friday 00:00 → Monday 23:59.

POST /admin/curriculum/:id/assignment Create assignment for a week ▶
PATCH /admin/assignments/:id Edit assignment ▶
GET /admin/assignments/:id/submissions Get all submissions ▶

PATCH /admin/submissions/:id/grade Grade a submission ▶
Assessments (Admin)

Create MCQ quizzes and file-upload assessments.

POST /admin/assessments Create assessment ▶
GET /admin/assessments/:id/results Get all results ▶

PATCH /admin/assessments/results/:id/score Set score manually ▶

Materials (Admin)

Upload files to Cloudinary and attach to a course or specific curriculum week.

DELETE /admin/materials/:id Delete material ▶

Note: Material upload requires multipart/form-data with a file. Use Postman or your frontend for file uploads — this tester handles JSON only.
Attendance (Admin)

Manage attendance sessions and view records.

POST /admin/attendance/sessions Open attendance session ▶
PATCH /admin/attendance/sessions/:id/close Close session ▶

GET /admin/attendance/sessions List sessions ▶

GET /admin/attendance List attendance records ▶

Payments (Admin)

View and manage student payment records. Total fee: ₦70,000. Instalment 1 deadline: 7 June. Instalment 2 deadline: 7 July.

GET /admin/payments List all payment records ▶

GET /admin/payments/summary Payment count summary ▶

PATCH /admin/payments/:studentId/override Manual payment override ▶
Curriculum (Student)

Returns all 12 weeks with materials and assignment windows. Auto-scoped to the student's cohort and course.

GET /student/curriculum Get curriculum ▶
Assignments (Student)

Submit and track assignments. Only open assignments (within Friday–Monday window) are returned.

GET /student/assignments Get open assignments ▶
GET /student/assignments/:id Get assignment details ▶

Assessments (Student)

View and submit MCQ and file-upload assessments.

GET /student/assessments List assessments ▶

GET /student/assessments/:id Get assessment + questions ▶

POST /student/assessments/:id/submit Submit MCQ answers ▶
Materials (Student)
GET /student/materials Get course materials ▶
Attendance (Student)
POST /student/attendance/check-in Check in (IP validated) ▶
Note: No body needed. Your IP is validated server-side against the active session's allowedIp.
GET /student/attendance My attendance history ▶
Grades

Submission history only — grades and scores are never shown to students.

GET /student/grades My submission history ▶
Payments (Student)

Check payment status, initiate Monnify checkout, and poll for confirmation.

GET /payments/status My payment status ▶
POST /payments/initiate Initiate payment → get checkout URL ▶

GET /payments/poll Poll payment confirmation ▶
How it works: Call this every few seconds after the student returns from the Monnify checkout page. Returns done: true when payment is confirmed or failed.
